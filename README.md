Dental Archwire Design System (Version 3.2)This project is a comprehensive system for designing custom lingual orthodontic archwires from 3D dental scans (STL files). It provides a graphical user interface (GUI) to load a dental model, automatically detect teeth, calculate an ideal wire path, generate bending instructions, and produce G-code for a custom wire bending machine. The system also allows for direct connection and control of an ESP32-based wire bender.Table of ContentsSystem ArchitectureKey FeaturesPrerequisites & InstallationHow to RunFile & Function ArchitectureThe application is built on a three-tier architecture, separating the user interface, the main processing logic, and the core 3D analysis.orthodontic_guiv4.py (Frontend)This is the main entry point for the user.Built with Tkinter, it provides the complete GUI for all operations.It handles user inputs, file loading, parameter selection, and invokes the backend processor.It displays the final results, visualizations, and manages the connection to the hardware.orthodontic_processor.py (Backend / Business Logic)Acts as a bridge between the GUI and the core 3D generator.Receives the file path and parameters from the GUI.Calls the CleanLingualWireGenerator to perform the heavy lifting.Post-processes the results from the generator into a user-friendly format (e.g., calculating wire length, generating clinical notes, creating bending instructions).Provides functions for exporting data to various formats (JSON, CSV, Report).tes_stl9claude_latestin.py (Core 3D Engine)This is the heart of the system where the 3D analysis happens.Uses the Open3D library to load, clean, and analyze the STL mesh.Implements algorithms for tooth segmentation, classification (incisors, canines, posteriors), and lingual bracket positioning.Generates the raw 3D wire path and creates visualization meshes (wire, brackets).Data Flow:GUI (Input) -> Processor (Manages) -> Generator (Analyzes) -> Processor (Formats) -> GUI (Displays)Key FeaturesSTL File Processing: Loads and analyzes standard 3D dental scan STL files.Automatic Tooth Detection: Segments the dental arch to identify individual teeth.Tooth Classification: Differentiates between incisors, canines, and posterior teeth.Lingual Wire Design: Calculates optimal bracket positions and a smooth wire path on the lingual (inner) surface of the teeth.Multi-View Visualization:2D top-down plot of the wire path.Static 3D preview of the wire on the dental model.Fully interactive 3D viewer (requires Open3D).Data Generation:Generates detailed, step-by-step bending instructions.Provides statistical analysis of the dental arch.G-Code Generation: Creates G-code compatible with a custom ESP32/Arduino-based wire bending machine.Hardware Integration:Directly connect to the wire bender via a serial (USB) port.Send G-code line-by-line with real-time feedback.Multiple Export Options: Save results as a JSON data file, CSV instructions, a comprehensive text report, or a G-code file.Prerequisites & InstallationTo run this application, you need Python 3 and the following libraries. You can install them using pip:pip install numpy open3d scipy matplotlib pyserial
numpy: For numerical operations.open3d: For all 3D mesh processing and visualization.scipy: Used for interpolation and signal processing in the core generator.matplotlib: For embedding 2D and 3D plots within the GUI.pyserial: For serial communication with the ESP32 hardware.How to RunEnsure all three Python files (orthodontic_guiv4.py, orthodontic_processor.py, tes_stl9claude_latestin.py) are in the same directory.Make sure you have installed all the required prerequisites (see above).Open a terminal or command prompt in that directory.Run the main GUI file:python orthodontic_guiv4.py
The "Dental Archwire Design System" window will appear, ready for use.File & Function Documentationorthodontic_guiv4.py (The Frontend)This file creates the entire graphical user interface using Tkinter.Class OrthodonticGUIThe main class that encapsulates the entire application.MethodDescription__init__(self, root)Initializes the main window, sets up styles, variables, and calls methods to create all UI components.setup_styles(self)Configures the application's visual style (colors, fonts) using ttk.Style.create_menu(self)Creates the top menu bar (File, View, Tools, Help).create_toolbar(self)Creates the main toolbar with quick-access buttons like Open and Process.create_main_layout(self)Sets up the main three-panel layout (Controls, Visualization, Results).create_left_panel(self, parent)Builds the left panel containing file info, parameters, actions, and the machine connection module.create_connection_panel(self, parent)Builds the specific frame for serial port selection and connection controls.create_center_panel(self, parent)Builds the central panel that houses the Notebook for switching between different visualizations.create_right_panel(self, parent)Builds the right panel for displaying text-based analysis and results.create_status_bar(self)Creates the status bar at the bottom of the window.open_file(self)Opens a file dialog to let the user select an STL file.show_file_info(self)Displays basic information about the loaded STL file.process_file(self)Initiates the wire generation process by calling the backend processor in a separate thread to keep the GUI responsive._process_file_thread(self)The target function for the processing thread. The X value is cumulative.G1 Y[angle]: Bends the wire to the specified angle. A positive angle might be clockwise, and a negative angle counter-clockwise.G1 Y0: Returns the bender mechanism to its neutral (zero-degree) position.M17 / M84: Enables / disables the stepper motors.; [comment]: Lines starting with a semicolon are comments and are ignored by the machine.Example Sequence:; ----- Step 2: Incisor #2 -----
G1 X25.3 F300 ; Feed wire to 25.3 mm total length
G1 Y12.5 F60  ; Bend 12.5 degrees
G1 Y0 F120    ; Return bender
Troubleshooting"Processor not available" error: Make sure orthodontic_processor.py is in the same folder as the GUI script.3D visualizations not working: This means Open3D or matplotlib is not installed correctly. See the Prerequisites section.Machine not connecting:Ensure pyserial is installed.Check that the correct COM port is selected.Verify the machine is powered on and connected to the computer.Poor Tooth Classification: The current algorithm is simple and works best on well-defined dental models. If classification is poor, the results may not be clinically valid. The accuracy is displayed in the results panel for review.
